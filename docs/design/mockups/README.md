# Demo app mockups

Static HTML mockups of the demo app, each showing light and dark: `first-run.html` (the first screen, the model sheet and the held message), `everyday.html` (the Sidebar layout), `app-layouts.html` (Sidebar beside Chat list) and `models.html` (search, the model sheet, Basic and Advanced sizes). Open them in a browser.
They are design documents from before the build and predate the final design system: they still show the nicknames Swift, Writer and Deep, the earlier message bar, and the earlier colours and type sizes.
The built app follows [../demo-app.md](../demo-app.md), which wins wherever the two differ.
