# Demo app mockups

Static HTML mockups of the demo app, each showing light and dark: `first-run.html` (the first screen, the model sheet and the held message), `everyday.html` (the Sidebar layout), `app-layouts.html` (Sidebar beside Chat list) and `models.html` (search, the model sheet, Basic and Advanced sizes). Open them in a browser.
`models-merged.html` (D116) is the final Models screen, drawn in the same tokens: the groups, a search with its loading slot and badges, the card's states (downloading, on this phone, not here, pulled up to the model's page) and the five fit symbols. It replaces the Get models part of `models.html` and `first-run.html`'s sheet, which show the earlier screens.
`voice-mode.html` (D100) is newer: it is drawn in the final design system's tokens and shows voice mode, which is not built yet.
The others are design documents from before the build and predate the final design system: they still show the nicknames Swift, Writer and Deep, the earlier message bar, and the earlier colours and type sizes.
The built app follows [../demo-app.md](../demo-app.md), which wins wherever the two differ.
